# ~/ernesto_aguaysol

![Porfolio](https://ernestoaguaysol.github.io/)

Sitio web personal de **Ernesto Aguaysol**, un desarrollador, docente e investigador enfocado en la intersección de la inteligencia artificial, sistemas de información y la filosofía del software libre.

Este proyecto utiliza una estética **terminal/cyberpunk** para reflejar una identidad técnica y soberana.

## 🚀 Sobre el Proyecto

Este es un sitio web de una sola página (SPA) estático, diseñado para presentar mi trayectoria profesional, habilidades técnicas y proyectos destacados de una manera inmersiva.

### 🛠️ Tecnologías Utilizadas

El sitio es puramente estático, sin necesidad de procesos de compilación, lo que garantiza una carga extremadamente rápida y una alta disponibilidad.

- **HTML5**: Estructura semántica del contenido.
- **CSS3 Avanzado**: Implementación de una estética cyberpunk mediante:
  - Variables CSS para un sistema de diseño consistente.
  - Efectos de *scanlines* (líneas de escaneo) y grano de ruido (*noise grain*) mediante gradientes y SVG.
  - Animaciones de *pulse* y *fade-in* para dinamismo.
  - Layouts complejos con **CSS Grid** y **Flexbox**.
- **JavaScript (Vanilla)**:
  - Animación de terminal tipo *typewriter* (máquina de escribir).
  - Implementación de `IntersectionObserver` para efectos de revelado al hacer scroll.
- **Google Fonts**: Uso de *JetBrains Mono* para la estética de terminal y *Syne* para títulos modernos.
